# ADR-004 17:30 고정 마감 + 하루 4회 수집

- 상태: 채택
- 날짜: 2026-09-28
- 관련: 02, SCH-R1~R8

## 맥락
18~20시에 읽을 리포트가 18시 전에 도착해야 한다. RSS는 최신 50건만 보여준다. GitHub Actions 예약 실행은 수십 분 늦어질 수 있다.

## 결정
- 마감을 17:30 KST로 **고정**하고 리포트 실행도 17:30에 시작한다.
- 수집은 23:00, 09:00, 13:00, 17:30 네 번 한다 (최대 간격 10시간).
- 범위 경계는 자정이 아니라 지난 마감 시각이다.

## 검토한 대안
- 17:50 마감: 실행 지연 시 18시를 넘길 수 있다.
- 자정 기준: 전날 저녁 글이 빠진다.
- 실제 실행 시각을 마감으로: 실행이 늦어진 날마다 범위가 달라져 테스트하기 어렵다.

## 결과
- 좋아지는 점: 범위가 매일 같고, 실패한 날 다음 리포트가 빈틈없이 이어받는다.
- 감수하는 점: 17:30~18:00 사이 글은 다음 날 리포트로 간다.
