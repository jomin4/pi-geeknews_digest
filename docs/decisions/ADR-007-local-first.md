# ADR-007 로컬 구현·테스트 후 클라우드 이관

- 상태: 채택
- 날짜: 2026-09-28
- 관련: 08, REQ-13, REQ-14

## 맥락
최종 목표는 폰으로 틈틈이 개선하는 것이지만, 처음 만들 때는 API 키 발급, Discord 봇 설정, 실제 호출 확인이 필요하다. Anthropic 관리형 클라우드 세션은 기본적으로 네트워크 접근이 제한된다.

## 결정
- T00~T10은 로컬에서 Claude Code로 구현하고, 실제 API 확인도 로컬에서 한다.
- 모든 자동 테스트는 외부 호출을 가짜 응답(fixture)으로 대체해 인터넷 없이 돈다.
- 이관 후 실제 API 호출은 GitHub Actions에서만 한다. 클라우드 세션에는 API 키를 두지 않는다.

## 검토한 대안
- 처음부터 클라우드 세션: 봇 설정·키 확인 같은 초기 작업을 폰으로 하기 불편하고, 네트워크 제한으로 실제 호출 확인이 어렵다.

## 결과
- 좋아지는 점: 클라우드 세션에서도 테스트가 그대로 돈다. 키가 한 곳(GitHub Secrets)에만 있다.
- 감수하는 점: fixture를 실제 응답과 같게 유지해야 한다. API 형식이 바뀌면 fixture도 갱신한다.
