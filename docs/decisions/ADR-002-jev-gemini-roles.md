# ADR-002 Jev는 판단, Gemini는 글쓰기

- 상태: 채택
- 날짜: 2026-09-28
- 관련: ARCH-05~08, 03, 05

## 맥락
LLM은 Gemini 무료 API를 쓰기로 했고, 새로 나온 판단 모델 Jev의 장점도 활용하고 싶다. Gemini 무료 티어는 분당 요청 수가 적어 50건을 하나씩 처리하기 어렵다.

## 결정
- Jev: 기사마다 분야·관심도·실무 활용·제외 여부를 판단하고, 요약이 원문에 근거하는지 검증한다.
- Gemini: 선별된 Top 5~8개 요약과 총평, 피드백 해석만 맡는다 (하루 최대 2회 호출).
- Jev는 OpenRouter의 Decisions API로 부른다 (대기자 명단 없이 API 키만으로 사용 가능).

## 검토한 대안
- Gemini 혼자 분류와 요약: 호출 수가 많아 무료 한도에 걸리고, JSON 안의 "확신도" 숫자는 보정된 확률이 아니다.
- TypeSafe 직접 API: 대기자 명단이 있다.

## 결과
- 좋아지는 점: 판단 비용이 매우 싸고(월 0.1달러 미만) 확률을 저장해 기준선을 나중에 조정할 수 있다.
- 감수하는 점: OpenRouter 소액 충전이 필요하다. Decisions API가 alpha 경로라 형식 변화에 대비해 응답을 검증한다(JEV-C7). 선택지 순서에 따라 확률이 흔들릴 수 있어 순서를 고정한다(JEV-C6).
