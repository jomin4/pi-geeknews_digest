# ADR-001 크롤링 대신 RSS로 수집

- 상태: 채택
- 날짜: 2026-09-28
- 관련: ARCH-02, SCH-R4, 00 §4

## 맥락
GeekNews 글을 매일 모아야 한다. 사이트 HTML을 읽거나 공식 피드를 쓸 수 있다.

## 결정
공식 Atom 피드 `https://news.hada.io/rss/news`만 쓴다. 제목·링크·게시 시각·작성자·요약문이 들어 있다.

## 검토한 대안
- 목록 페이지 크롤링: 구조가 바뀌면 깨지고, 이용 부담을 준다.
- 개별 글 페이지 본문 읽기: 브라우저 확인 화면이 떠서 프로그램으로 읽을 수 없다.
- GeekNews 공식 Discord 봇: 새 글을 전부 보내줄 뿐 선별·요약이 없다.

## 결과
- 좋아지는 점: 안정적이고 가볍다.
- 감수하는 점: 피드가 최신 50건만 보여줘 하루 여러 번 수집해야 한다(ADR-004). 요약문이 잘려 있어 요약 품질에 한계가 있다(GEM-A1, JEV-V1). 주제 카테고리가 없어 Jev로 분류한다.
