# ADR-006 Top이 부족해도 채우지 않음

- 상태: 채택
- 날짜: 2026-09-28
- 관련: JEV-R5, DSC-08

## 맥락
Jev 판단 설계에서는 "Top이 5개 미만이면 다음 순위로 채움"이라고 했고, Discord 양식 설계에서는 "기준 미달 글을 억지로 올리지 않음"이라고 했다. 두 규칙이 충돌했다.

## 결정
채우지 않는다. Top은 기준을 넘은 글만 최대 8개. 0개인 날은 "오늘은 관심 분야 글이 적었어요"로 알린다.

## 검토한 대안
- 5개까지 채우기: 매일 모양은 일정하지만, Top의 의미가 흐려지고 주간 보정 신호가 오염된다.

## 결과
- 좋아지는 점: Top에 있다는 것이 항상 같은 뜻이다. 평가 데이터가 깨끗하다.
- 감수하는 점: 글이 적은 날은 Top이 짧다. 기준이 너무 높으면 주간 보정(FB-20)으로 낮춘다.
