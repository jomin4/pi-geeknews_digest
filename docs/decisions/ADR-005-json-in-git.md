# ADR-005 DB 없이 JSON을 git에 저장

- 상태: 채택
- 날짜: 2026-09-28
- 관련: 04, DATA-R1~R7

## 맥락
수집함, 상태, 취향, 평가, 리포트 기록을 실행 사이에 보존해야 한다. 상시 서버와 DB는 두지 않는다.

## 결정
`data/` 폴더에 JSON 파일로 두고, 실행이 끝날 때마다 GitHub Actions가 커밋한다.

## 검토한 대안
- 클라우드 DB(무료 티어): 계정·키가 하나 더 늘고, 폰에서 내용을 바로 보기 어렵다.
- Actions 캐시·아티팩트: 보관 기간이 짧고 사람이 읽기 불편하다.

## 결과
- 좋아지는 점: 폰에서 GitHub로 파일을 열어 바로 확인할 수 있고, 변경 이력이 커밋으로 남는다.
- 감수하는 점: 커밋이 하루 4번 쌓인다. 동시 실행을 막아야 한다(02 §3). 90일 보관으로 크기를 제한한다(DATA-R3).
