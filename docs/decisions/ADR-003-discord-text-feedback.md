# ADR-003 Discord 전달 + 텍스트 피드백

- 상태: 채택
- 날짜: 2026-09-28
- 관련: 06, 07, FB-01

## 맥락
리포트를 받을 곳과 피드백을 남길 방법을 정해야 한다. 상시 서버는 두지 않는다.

## 결정
- 리포트는 Discord 리포트 채널에 임베드로 보낸다.
- 피드백은 Discord 피드백 채널에 **자유 텍스트**로 남긴다. 봇은 17:30 실행 때 읽는다.
- 리포트의 모든 글에 번호를 붙여 "3번 별로"처럼 가리킬 수 있게 한다.

## 검토한 대안
- 👍/👎 이모지 반응: 처음 설계안이었다. "무엇이 좋은지"를 말할 수 없어 텍스트로 바꿨다.
- Discord 버튼: 누르는 즉시 응답하려면 상시 서버가 필요하다.
- 텔레그램: 구조는 같다. Discord를 이미 쓰고 있어 Discord로 정했다.

## 결과
- 좋아지는 점: 취향을 말로 설명할 수 있고 서버가 필요 없다.
- 감수하는 점: 답장은 즉시 오지 않고 다음 실행 때 온다. 텍스트 해석에 Gemini 호출이 하루 1회 더 든다. Message Content Intent를 켜야 한다.
