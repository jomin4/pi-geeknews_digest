# ADR-008 포트폴리오 증거를 위해 실행 지표를 처음부터 기록

- 상태: 채택
- 날짜: 2026-09-28
- 관련: DATA-06, ARCH-12, T13, T14, portfolio/README.md

## 맥락
이 프로젝트는 포트폴리오용이다. 포트폴리오의 문제 해결 경험은 "제목 → 그림 → 문제 → 해결 과정 → 결과"로 쓰고, 결과에는 **테스트 조건과 함께 전후 수치**가 있어야 한다. 구현이 끝난 뒤에 수치를 모으려 하면 이미 지나간 실행의 데이터가 없다.

## 결정
- 구현 첫 작업부터 실행마다 지표(호출 수, 비용, 지연, 섹션 수, 오류)를 `data/metrics.jsonl`에 한 줄씩 남긴다.
- 구현 중 생긴 문제는 그때그때 `portfolio/logs/`에 사실대로 기록한다.
- 측정용 실험은 `experiments/`에 두고, 원본 결과는 `portfolio/evidence/`에 보관한다.
- 포트폴리오 문장의 최종 작성·확정은 사용자가 한다. Claude Code는 기록과 초안까지만 한다.

## 검토한 대안
- 구현 후 한꺼번에 측정: 개선 전 상태를 재현하기 어렵고, 운영 기간 데이터가 없다.
- 외부 모니터링 도구: 이 규모에 과하고 계정이 늘어난다.

## 결과
- 좋아지는 점: 결과 수치를 스크립트로 다시 만들 수 있고, 면접에서 근거 파일을 보여줄 수 있다.
- 감수하는 점: 작업마다 지표 필드를 추가하는 일이 조금 늘어난다. 지표에 비밀값이 섞이지 않도록 주의해야 한다.
