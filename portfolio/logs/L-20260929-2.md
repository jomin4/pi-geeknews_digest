# L-20260929-2 RSS 제목에 HTML 엔터티가 한 번 더 들어 있어 `&amp;`가 그대로 보임

- 날짜: 2026-09-29
- 작업: T01 · 환경: 클라우드 세션
- 관련 설계 ID: DATA-01
- 연결 후보: 없음 (외부 응답 형식)
- 기록: Claude Code

## 상황
feedparser로 저장본을 읽어 제목을 확인하던 중.

## 현상
```
<title><![CDATA[Regression Testing: Techniques, Tools &amp; Best Practices]]></title>

>>> feedparser.parse(raw).entries[1].title
'Regression Testing: Techniques, Tools &amp; Best Practices'
```

## 원인
GeekNews가 제목을 HTML 이스케이프한 뒤 CDATA로 한 번 더 감싼다. CDATA 안의 `&amp;`는 XML에서 풀리지 않는 글자 그대로라, feedparser 결과에도 `&amp;`가 남는다. `grep -o "<title><!\[CDATA\[[^]]*&amp;" tests/fixtures/rss_sample.xml`로 원문에서 확인했다 (50건 중 1건).

## 시도
| # | 시도한 방법 | 결과 |
|---|---|---|
| 1 | 제목에 `html.unescape` 적용 | `Tools & Best Practices`로 정상 |

## 선택과 이유
제목에만 `html.unescape`를 한 번 적용한다. 본문(`content`)은 HTML로 읽어 태그를 없애는 과정에서 엔터티도 풀리므로 따로 처리하지 않는다. DATA-01 필드 표에 제목 처리 규칙을 한 줄 추가했다.
