# 측정 증거 보관 규칙

포트폴리오 결과 수치의 **원본**을 둔다. PDF에 쓰는 모든 숫자는 여기 있는 파일로 되돌아가 확인할 수 있어야 한다.

## 폴더

```
evidence/
├─ P1/
│  ├─ 2026-10-06-coverage.md    측정 설명 (아래 형식)
│  └─ 2026-10-06-coverage.csv   원본 결과
├─ P2/ …
└─ R1/ …
```

## 측정 설명 파일 형식 (`날짜-이름.md`)

```markdown
# 측정: 한 줄 이름
- 목적: 어떤 후보(P?)의 어떤 지표를 위한 측정인가
- 날짜·기간: 
- 명령: `uv run python experiments/p1_coverage.py --from 2026-10-01 --to 2026-10-07`
- 환경: OS, Python, 실행 위치(로컬/Actions), 모델 버전(jev-1.13, Gemini 모델명)
- 데이터 범위: 기사 수, 기간, 제외한 것과 이유
- 결과 요약: 핵심 숫자 2~3개
- 원본 파일: `…csv`
- 한계: 이 측정으로 말할 수 없는 것
```

## 규칙

- 원본 결과 파일은 **수정하지 않는다.** 다시 측정하면 새 날짜로 새 파일을 만든다.
- 집계·그래프는 `experiments/`의 스크립트로 원본에서 다시 만들 수 있어야 한다.
- 비밀값, 개인 식별 정보(Discord 사용자 ID 등)는 넣지 않는다.
- 실제 API를 부르는 측정은 비용·한도를 설명 파일에 적는다.
